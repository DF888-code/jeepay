# 版本紀錄

部署包檔名格式：`project-hub-htdocs-v{版本}-{日期}.zip`。網站登入後頁尾會顯示目前版本。
版本號規則：`0.{階段}.{修正}`，正式上線（階段 12 完成）後改為 1.0.0。

| 版本 | 日期 | 內容 |
|---|---|---|
| 1.1.4 | 2026-11-04 | 猜帳號封鎖：同一 IP 在鎖定時間內輸入不存在的帳號達 5 次（系統設定可調 3–50），暫時封鎖該 IP 的所有登入與救援申請，並在歷史紀錄留下「暫時封鎖 IP」。不需資料庫更新 |
| 1.1.3 | 2026-11-04 | 登入頁不再常駐救援入口：任何帳號輸入錯誤密碼或驗證碼後，才顯示「申請帳號協助」連結（所有帳號一致，無法藉此判斷誰是管理者）；救援相關頁面與信件改用中性用詞「帳號協助／帳號救援」。不需資料庫更新 |
| 1.1.2 | 2026-11-04 | 隨手記修改紀錄改為只有作者本人與最高權限管理者能看（其他員工沒有入口，直接開網址為「找不到頁面」）；紀錄頁改為一列一筆的三欄版面「修改前｜修改後｜時間／修改者」，手機自動改為上下排列。不需資料庫更新 |
| 1.1.1 | 2026-11-03 | Cloudflare R2 改為填寫「S3 API 端點」（原本由帳戶 ID 推算），支援歐盟儲存區的 bucket；可直接貼上 Cloudflare 顯示的含 bucket 網址，系統自動拆開；只接受 R2 官方網址格式。不需資料庫更新 |
| 1.1.0 | 2026-11-03 | 換頁與表單送出不再整頁重新載入（Hotwire Turbo）；管理後台各頁在完成身分驗證前只顯示驗證框；**隨手記修改與刪除紀錄**（保存修改前後與刪除前的完整內容，需套用資料庫更新 0005）；**附件可存到 Cloudflare R2**（含申請與設定步驟、測試連線）；附件儲存頁註明 OneDrive 尚未支援的原因 |
| 1.0.1 | 2026-11-02 | 專案關鍵字新增／移除改為局部更新，不再重新載入整頁（無 JavaScript 時自動改用原本的表單）。新增「管理後台 → 系統錯誤」：錯誤頁上的追蹤代碼可查詢詳細原因（InfinityFree 不提供 PHP 錯誤日誌），錯誤寫入 storage/logs，保留 3 個月，不記錄網址參數與表單內容；記憶體不足等致命錯誤也會顯示追蹤代碼。不需資料庫更新 |
| 1.0.0 | 2026-11-02 | 階段 12：正式版。全站安全掃描（所有路由的未登入、越權、CSRF 檢查）與 Apache 部署驗證。安全修正：未設定 base_url 時不寄救援信（防止 Host 標頭偽造竊取救援連結）、網址含 NUL 字元不再造成錯誤、不再透露 PHP 版本、JSON 輸出跳脫 HTML 字元。新增安全測試報告（docs/09）與正式上線檢查清單。不需資料庫更新 |
| 0.11.0 | 2026-11-02 | 階段 11：手機與平板版面改善。超長專案名稱、網址、關鍵字不再撐破畫面；手機按鈕加大（至少約 40 px），避免誤觸；iOS 輸入時不自動放大；歷史紀錄的篩選條件在手機上可摺疊。不需資料庫更新 |
| 0.10.0 | 2026-11-02 | 階段 10：最高權限管理者 Email 救援（忘記密碼／遺失驗證器／兩者都遺失），連結只能用一次、30 分鐘有效、開啟連結不會直接生效；兩者都遺失需等待 30 分鐘；完成後寄送通知並登出所有裝置。帳號設定新增「Email 救援設定」（變更救援 Email、取消救援申請）。不需資料庫更新 |
| 0.9.0 | 2026-11-02 | 階段 9：系統設定中心（一般設定、寄信設定、附件儲存位置）。所有設定在畫面上修改並記錄新舊值；SMTP／Brevo API 寄信與「測試連線」「寄送測試信」；**附件可改存 Google Drive**（OAuth 連結、只要求 drive.file 權限、Token 加密保存、經 PHP 代理維持雙重授權、舊檔留在原處）。需套用資料庫更新 0004 |
| 0.8.0 | 2026-11-02 | 階段 8：歷史操作紀錄查詢介面（單日／日期範圍、員工、類型篩選與組合）、統計（總數、首次／最後操作、上午／下午次數、每小時分布圖）、CSV 匯出（防公式注入）、保存期限設定與自動清理。不需資料庫更新 |
| 0.7.0 | 2026-11-02 | 階段 7：全站搜尋（專案名稱、說明、關鍵字、隨手記），支援繁簡字形與兩岸用語互搜（「資料庫」↔「数据库」、「記憶體」↔「内存」），只搜尋有權限的專案；關鍵字以相同規則防止重複；管理後台提供搜尋索引重建。不需資料庫更新，但升級後需在「管理後台 → 專案管理」重建搜尋索引一次 |
| 0.6.0 | 2026-11-02 | 階段 6：專案說明編輯（多人同時編輯不互相覆蓋、衝突時保留未儲存文字）與完整版本歷史、專案關鍵字、隨手記（新增／修改／刪除、分頁）、**隨手記圖片與附件上傳**（拖拉、多檔、手機選取、圖片直接顯示與放大、附件下載，繼承專案雙重授權）。需套用資料庫更新 0003 |
| 0.5.0 | 2026-11-02 | 階段 5：建立專案、專案列表（只顯示有權限的專案）、專案詳細頁、改名、刪除（回收區，可由管理者還原）、後台專案管理與每個專案的授權名單、雙重授權全面套用於頁面與 API；重設密碼與重設 2FA 改為每次都需輸入驗證碼 |
| 0.4.1 | 2026-11-02 | 安全修正：登出後「管理者已完成身分驗證」狀態殘留在 Session 中，同一瀏覽器重新登入仍可免驗證執行管理操作。改為登出或登入時清空整個 Session（只保留提示訊息），並更換 CSRF Token |
